python_lab

📈 A Minha Jornada A ideia aqui é mostrar que todo programador começa do básico. Neste repositório, você vai encontrar a evolução dos meus códigos, refatorações e a aplicação prática de conceitos fundamentais da lógica de programação.

📂 Organização das Pastas (ou Tópicos)

01_Primeiros_Passos/

O início de tudo: impressões na tela (print), o tradicional Hello, World!, e os primeiros testes de sintaxe.

02_Variaveis_e_Tipos/

Manipulação de variáveis, recebimento de dados com input() e conversões básicas de tipos (int, str, float).

03_Condicionais/

O uso de if, elif e else para tomadas de decisão no código, controlando fluxos e caminhos diferentes.

04_Validacoes_e_Logica/

Scripts mais avançados focados em tratamento de dados, como checagem de tamanhos (len), verificação de dígitos (isdigit) e regras de limites numéricos (validação de datas, por exemplo).

05_Loops_e_Iteracoes/ (Em breve / Em construção)

Automatização de tarefas e repetições usando estruturas de loop (for e while).
